# 第1候補: pack全域の固定hash順位ゲーム・E3

固定development 5局・100万ノード比較は有効で、候補は**不採用**。現採用モデルを維持する。

| 指標 | 現採用E3 | 多様化データE3 |
| --- | ---: | ---: |
| MAE（cp、低いほどよい） | 907.671621 | 966.372955 |
| Top3入り率 | 59.951320% | 57.054274% |

両指標は各局の整数集計から算出した5局等重みの有理数で比較した。MAEの厳密低下とTop3非低下の共同条件を満たさない。8項目の比較identity一致、両モデル自身のMAE/Top3各pilot・formalの全raw再検証、比較入力と最新best登録の前後不変を確認した。[分子・分母と各局の集計](comparison.json)を参照。

同じモデル構造・初期化・更新量で、教師packの各prefixから選ぶ方法を全pack内の固定hash順位ゲームへ変更した。学習112,681局面・3epoch、固定holdout5,895局面を維持した。この条件では改善に至らず、データの多様化一般が無効とは結論しない。

通常Pythonによる初回起動はTop3 pilot前に依存欠落で停止した。完了済みの候補自身のMAE rawを再検証し、固定audit環境でTop3の2段階を新規実行した。最新best照合の補助処理の辞書形式差も別記録で再検証した。両失敗原本を保持し、正式比較の成功やモデル採用に書き換えていない。

[評価値の公開グラフ](mae/reviewed.svg)と[MAEの検証集計](mae/validation.md)を保存する。final5局は未使用。学習・技術検証とモデル採否を分け、期間内の次の仮説選定へ進む。
